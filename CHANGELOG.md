# Changelog

All notable changes are documented here.

## 0.1.0 - 2026-08-18

- Add immutable typed request context and strict lexical scopes.
- Add MDC projection with nested restoration and leak prevention.
- Add Servlet, RestClient, WebClient, Reactor, and Kafka adapters.
- Add executor, `@Async`, platform-thread, virtual-thread, and OpenTelemetry context propagation.
- Add deadline handling, safe headers, Spring Boot auto-configuration, and deterministic tests.
